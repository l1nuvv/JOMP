# Десять советов из Heist Crew

| 2 | Подключить скиллы и MCP | Используем имеющийся Unity MCP и навыки по задаче. Кадры, Console и автоматизированные проверки дополняются ручной проверкой ввода и ощущений. [Правила проекта](../AGENTS.md) |
| 3 | Адаптировать готовые риги и анимации из Mixamo | Сначала использовать совместимый имеющийся риг и поставить три хвата. К Mixamo вернуться при потребности в анимации всего тела и после проверки конкретного ассета. [Арт-направление](ART_DIRECTION.md) |
| 4 | Брать готовые ассеты из BlenderKit | Использовать существующие и проверенные бесплатные кандидаты под конкретные места. BlenderKit можно рассмотреть при пробеле в поиске и после проверки лицензии конкретного файла. [Источники ассетов](ASSET_SOURCES.md) |
| 5 | Делать собственные модели в Blender по концепту | Применить референс формы и хват в игровом кадре к отпаривателю. Для плакатов сначала определить форматы, содержание и перекрытия одного участка. [Арт-направление](ART_DIRECTION.md) |
| 6 | Генерировать звук и музыку в ElevenLabs или локально | Перенести акцент на слышимый результат. Прослушать существующие отрывы трёх инструментов и проверить совпадение с выплатой. При выявленном пробеле искать подходящую бесплатную запись. [Бэклог звука](DEVELOPMENT_BACKLOG.md#au--звук-и-атмосфера) |

| 8 | Держать отдельные копии проекта и редактора для агентов | Использовать отдельный worktree при независимом эксперименте, который оправдывает отдельный импорт Unity. [Процесс разработки](DEVELOPMENT.md#isolated-experiments-and-local-history) |
| 9 | Разделить роли моделей | Разделять поиск референсов, реализацию и проверку результата по их результатам и доказательствам. Качество руки, инструментов и плакатов оценивает владелец по интегрированному результату. [Правила проекта](../AGENTS.md) |
| 10 | Вести локальную историю Git | Продолжать в существующем репозитории. Когда задача включает коммит, выделять в истории проверенное изменение по задаче. [Процесс разработки](DEVELOPMENT.md#isolated-experiments-and-local-history) |
